# P14 五类测试总账矩阵（任务书§51）

一行一条用例。**状态口径**（写死在 `tests/p14-module-tables.test.mjs` 里，混用会红）：

- `已做` = 我这边自动化/静态已覆盖（Node 用例、构建校验、代码检索）；
- `已验` = 用户在游戏内跑过并确认（只有真机项可以是这个值）；
- `待办` = 还没人验；
- `本机不可验` = 这台机器/这个环境做不到（保留在台账§八，不阻塞阶段）。
